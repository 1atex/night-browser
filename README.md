# Night Browser

Night — браузер для Windows на Firefox/Gecko, со своей оболочкой и инструментами для работы с запросами. Оформление на основе Night Island, рабочие области, вертикальные вкладки, разделение экрана и управляемая выгрузка страниц.

Night использует Mozilla Firefox напрямую. Код оболочки, патчи, сборочные инструменты и модули Zen удалены. История первого прототипа сохранена в Git.

## Что работает

- Обновление установленной Windows-версии из настроек: загрузка, проверка SHA-256, перезапуск с сохранением профилей и страница изменений.
- Night Together: ID, подтверждение дружбы, имена и аватары из набора, приглашения и комнаты по ссылке. Совместное HTML5-видео с общими play/pause, перемоткой и скоростью. Приглашения по ссылке с допуском владельцем, P2P-чат и голос WebRTC, видео рядом с комнатой. Привязка включается явно; TURN для сложных сетей настраивается отдельно. [Docker-сервер и установка](services/together/INSTALL.md).
- Приватное окно по `Ctrl+Shift+N` и `Ctrl+Shift+P`.
- Локальные профили с отдельными паролями, cookies, расширениями и оформлением; переключатель внизу панели; настройка имени, цвета и значка.
- Явное подключение Mozilla Sync в каждом профиле, выбор данных и синхронизация выбранных настроек Night. [Профили и ограничения Sync](docs/night/PROFILES.md).
- Рабочие области с отдельными вкладками и восстановлением после перезапуска. Пространство вместе с папками можно свернуть; состояние сохраняется.
- Общие избранные сайты, закрепления внутри пространства, вложенные папки и перенос мышью между ними.
- Адрес и навигация в боковой панели или сверху. Ширина панели меняется перетаскиванием края; плотность и видимость элементов настраиваются.
- Две страницы рядом: `Alt+S`. Скрытие боковой панели: `Alt+B`. Поиск вкладки: `Alt+P`.
- Автоскрытие верхней панели и режим «Только сайт»: `Alt+Shift+F`. Адресная строка появляется поверх страницы по `Ctrl+L` или у верхнего края окна.
- Favicon сайтов в адресной строке, вкладках и закреплениях; спокойный фокус в адресной строке и поиске. Компактный адрес с меню разрешений, закладок и масштаба; подробные значки включаются отдельно, активная камера/микрофон остаются видимыми.
- Таймер выгрузки неактивных страниц, исключения по домену и по вкладке. Активные страницы, split view, аудио, PiP, звонки и перехватываемые запросы защищены.
- Repeater и перехват HTTP(S) в выбранной вкладке: изменение URL в пределах origin, метода, заголовков и текстового тела; просмотр ответа и сравнение последних ответов.
- Расширения и DevTools Firefox. Адресная строка, проверка сертификатов, разрешения и изоляция сайтов остаются механизмами Firefox.
- Локальный импорт профиля Zen: закладки, история, пароли, cookies, расширения, вкладки и области, с резервной копией Night.
- Короткие анимации вкладок, областей и меню; поддержка уменьшения движения без фоновой анимации.
- Собственные настройки, четыре палитры, плотность и ширина панели; русская локализация.
- Настраиваемая стартовая страница: часы, быстрые ссылки, вкладки пространства и действия Island. Клик на новую вкладку сразу фокусирует поиск. Подсказки из истории, закладок и выбранного поисковика, управление стрелками, Enter и Esc. Скрытая главная приостанавливает виджеты и подписки; библиотеки Activity Stream не загружаются.
- Общая палитра Night для служебных страниц, расширений, паролей, загрузок, библиотеки, диалогов, DevTools и сетевых инструментов. Системные окна Windows и содержимое расширений используют собственное оформление.
- Имя, значок, ресурсы EXE и идентичность окна Windows — Night.
- Установщик для текущего пользователя и мастер первого запуска с оформлением и импортом Zen.
- Управление окном справа сверху при наведении; постоянная видимость включается в настройках.
- Крестик у сохранённой вкладки отправляет её в сон, сохраняя папку и состояние. Удаление доступно отдельно в контекстном меню.
- Индикатор Island сверху или снизу боковой панели, показ только незавершённых загрузок, переход в настоящий Island и общее оформление. Все параметры меняются отдельно.
- Загрузки в Night Island: прогресс, пауза, продолжение, отмена и показ файла. Включается отдельно в обоих приложениях; состояние подключения и повторное подключение доступны в настройках.
- Поиск вкладок из Island по `Ctrl+Alt+B`, с favicon и путём папок. Спящие страницы просыпаются только после выбора.
- «Карман» Island для явно сохранённых ссылок, текста и ссылок на изображения: контекстное меню или перетаскивание, источник, копирование, заметка и удаление с отменой. До 100 материалов, локальное хранение.
- Активность вкладок и управление звуком из Island; пропуск, отклонение и переход к редактированию перехваченного запроса. Эти возможности включаются отдельно, приватные вкладки исключены.
- Обновление изменившихся строк боковой панели без перезаписи остального дерева вкладок.

Сайт браузера и счётчик реальных скачиваний GitHub входят в Docker-сервис Together. [Установка сайта, комнат и опционального TURN](services/together/INSTALL.md).

## Запуск и разработка

[Установщик Night 0.14.0 для Windows x64](https://github.com/1atex/night-browser/releases/download/v0.14.0-preview.1/night-browser-0.14.0-preview-windows-x64-setup.exe) · [Portable ZIP](https://github.com/1atex/night-browser/releases/download/v0.14.0-preview.1/night-browser-0.14.0-preview-windows-x64.zip) · [Релиз и контрольные суммы](https://github.com/1atex/night-browser/releases/tag/v0.14.0-preview.1)

[Сервер Together для Docker](https://github.com/1atex/night-browser/releases/download/v0.14.0-preview.1/night-together-server-0.14.0.zip) · [Команды установки](services/together/INSTALL.md). Адрес browser.night-watchers.com встроен в клиент; сервис разворачивается владельцем VPS.

Для интеграции нужен [Island 0.4.0 на основе 7d9bc80](https://github.com/1atex/night-island/releases/tag/v0.4.0-browser-preview.1). Точная совместимая ревизия записана в `scripts/preview/island.json` и BUILD.json; сборка проверяет наличие этой основы в истории.

Установщик работает без прав администратора. Приложение находится в `%LOCALAPPDATA%\Programs\Night Browser`, профиль — в `%LOCALAPPDATA%\NightBrowser\profile`. Первый запуск новой сборки автоматически обновляет кэш интерфейса, сохраняя профиль. Повторная установка обновляет приложение; удаление программы сохраняет профиль. Выбор браузера по умолчанию остаётся за пользователем в настройках Windows.

Для portable распакуй всю папку и запусти `Night.exe`; профиль создаётся рядом в `profile`. Обе версии выпускаются через [GitHub Actions](https://github.com/1atex/night-browser/actions/workflows/windows-preview.yml). Установленная версия и portable используют разные профили. Для переноса данных уже настроенного Night закрой обе копии, сохрани резервные копии и замени содержимое нового профиля содержимым прежней папки `profile`. Папка `profile` содержит только основной профиль; дополнительные профили и правила резервного копирования описаны в [Профили и Sync](docs/night/PROFILES.md). Профиль Zen удобнее переносить через мастер первого запуска.

[Импорт из Zen](docs/night/ZEN_IMPORT.md) · [О дизайне и лицензиях](docs/night/DESIGN_PROVENANCE.md)

[Инструкция по сборке](docs/night/CONTRIBUTING.md) · [Проверки](docs/night/VALIDATION.md) · [Архитектура](docs/night/PRODUCT.md)

Сборка проверяет SHA-256 официального Firefox, добавляет исходники Night, заменяет Windows-ресурсы приложения, собирает launcher и запускает тесты на Windows. Обычный первый запуск проверяется отдельно, без режима автоматизации. Нативный Gecko используется готовым; его исходники и точная ревизия указаны в `scripts/preview/runtime.json`. Это позволяет менять продукт без компиляции движка при каждой правке интерфейса.

Экономия памяти проверяется отдельным воспроизводимым тестом. Его синтетические результаты не являются замером YouTube, ChatGPT или Censys; ускорение рендеринга пока не заявляется.

Обновления установленной версии запускаются из настроек; portable обновляется вручную. Подписи Windows пока нет. MPL-2.0.
