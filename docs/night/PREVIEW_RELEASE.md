# Night Browser 0.9.2 Preview

- Исправлено подключение к Island после повторного скачивания: `night-island (1).exe`, `night-island (2).exe` и другие нумерованные копии теперь распознаются автоматически.
- В настройках интеграции видна причина сбоя: Island не запущен, Windows запретила доступ, соединение занято, имя приложения не распознано или версия протокола несовместима. При наличии отображается код ошибки Windows.
- После успешного подключения сообщение об ошибке очищается. Автоматическое переподключение и кнопка ручного повтора сохранены.

Совместим с уже выпущенным [Island 0.3.2](https://github.com/1atex/night-island/releases/tag/v0.3.2-browser-preview.1); повторно скачивать Island не требуется. Включи **Загрузки Night Browser** в настройках Island и **Показывать загрузки в Island** в браузере. Приватные загрузки, адреса страниц и полные пути не передаются.

Установщик обновляет файлы браузера, сохраняя профиль. Перед установкой закрой Night Browser. ZIP доступен для переносной установки.
