# Night Browser 0.12.0 Preview

- `Ctrl+Shift+N` открывает приватное окно; штатное `Ctrl+Shift+P` сохранено. Внизу панели виден индикатор приватного сеанса.
- Переключатель локальных профилей: отдельные пароли, cookies, расширения, закладки, вкладки и оформление. Можно создать пустой профиль, выбрать палитру и переименовать его. Повторный выбор возвращает к уже открытому окну; launcher помнит последний выбранный профиль.
- «Настройки → Профили и Sync»: явное подключение аккаунта Mozilla через штатный OAuth/WebChannel, выбор данных, состояние синхронизации и выход с подтверждением. Палитра и выбранные настройки Night включены в механизм синхронизации настроек.
- Импорт Zen больше не копирует авторизацию Sync. Локальные пароли, закладки и прочие данные продолжают импортироваться с резервной копией.
- Существующий профиль и настройки сохраняются. Новые профили хранятся отдельно; закреплённые окна Windows запускают именно свой профиль.

Sync использует аккаунт Mozilla. Вход в Google на сайте не переключает профиль и не подключает Chrome Sync. Cookies и структура папок Night через Sync не передаются. Каждый открытый профиль использует отдельные процессы и память. Проверки не включают вход в реальный аккаунт и перенос его данных между устройствами.

Установщик обновляет приложение с сохранением профилей. Для интеграции подходит [Island 0.4.0](https://github.com/1atex/night-island/releases/tag/v0.4.0-browser-preview.1); обновлять Island для этого выпуска не требуется.

Основа — нативный Mozilla Gecko 160.0; браузер пока не подписан цифровой подписью и не обновляется автоматически. Изменение движка JS/CSS и сокращение памяти активного YouTube в этом выпуске не заявляются.
