# Night Browser 0.10.0 Preview

- Поиск на главной теперь показывает историю, закладки и подсказки выбранного поисковика. Иконки берутся из кэша. Поддерживаются стрелки, Enter, Esc и закрытие по клику снаружи; настройки сетевых подсказок общие с адресной строкой.
- Адресное поле в боковой панели плавно раскрывается и возвращается в компактный вид. Esc закрывает его и возвращает фокус странице. Учитываются отключение анимаций и уменьшение движения в системе.
- **Поиск вкладок из Island:** Ctrl+Alt+B, favicon и путь папок. Спящие страницы загружаются только после выбора.
- **Карман:** сохранение выделенного текста, ссылок и ссылок на изображения через контекстное меню или перетаскивание в Island. Копирование, источник, перенос в заметку, удаление с отменой. Материалы сохраняются после перезапуска.
- **Активность:** источник звука, камеры, микрофона и демонстрации экрана, переход к вкладке и переключение звука.
- **Перехват:** ожидающий запрос виден в острове; его можно пропустить, отклонить или открыть для редактирования в браузере.

Нужен [Island 0.4.0](https://github.com/1atex/night-island/releases/tag/v0.4.0-browser-preview.1). В Island включи **Настройки → Интеграции → Связь с Night Browser**, затем включи нужные возможности в настройках интеграции браузера. Новые возможности включаются отдельно. Приватные вкладки, тела и заголовки запросов автоматически не передаются. Карман хранит до 100 материалов; изображения сохраняются как ссылки.

Общие цвета, акцент, анимации и управление загрузками сохранены. Установщик обновляет файлы браузера и кэш интерфейса, сохраняя профиль. Перед установкой закрой Night Browser. ZIP доступен для переносной установки. Preview без подписи Windows и автоматического обновления.
