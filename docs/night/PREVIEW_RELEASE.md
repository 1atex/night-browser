0.8.0 — установщик, первый запуск и сохранение вкладок в папках.

- Windows-установщик для текущего пользователя: ярлыки, регистрация в списке браузеров по умолчанию, обновление поверх предыдущей установки и удаление приложения. Профиль хранится отдельно в `%LOCALAPPDATA%\NightBrowser\profile` и сохраняется после удаления приложения.
- Мастер первого запуска: оформление и расположение навигации, импорт Zen с резервной копией, основные сочетания клавиш. После завершения он не появляется снова.
- Кнопки окна перенесены в правый верхний угол. По умолчанию появляются при наведении; постоянная видимость включается в настройках внешнего вида.
- Крестик у вкладки в папке или закреплённой в пространстве выгружает страницу, сохраняя её место. Несохранённые изменения проходят проверку Gecko. Для удаления есть отдельное действие в контекстном меню. Спящие вкладки имеют приглушённые значки и подпись «Спит».
- Стили оболочки подключаются до первого отображения окна. Стартовый каркас Firefox отключён для исполняемого файла Night.

**Ctrl+L** — адрес, **Alt+P** — поиск вкладок, **Alt+B** — боковая панель, **Alt+Shift+F** — только сайт.

Выбери `setup.exe` для установки или ZIP для portable-версии. У portable профиль остаётся в папке `profile` рядом с `Night.exe`. Для обновления portable закрой браузер и замени файлы приложения, сохранив `profile`. Установленная версия и portable используют разные профили. Чтобы перенести существующий профиль Night в установленную версию, закрой обе копии, сохрани резервные копии и скопируй содержимое прежней папки `profile` в `%LOCALAPPDATA%\NightBrowser\profile`, заменив новый профиль.

Основа — Gecko 160.0. Автоматическое обновление отключено. Windows-приложение и установщик пока не подписаны. Сведения о движке и лицензиях сохранены в BUILD.json, разделе «О браузере» и about:license. Интеграция с Island описана как предложение в `docs/night/ISLAND_INTEGRATION.md`; нового соединения между приложениями в этой версии нет.
