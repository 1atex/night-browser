# Night Browser 0.18.0 Preview

- Выбор обычной вкладки снимает оставшуюся разметку split view, сохраняя пару вкладок для возвращения. Проверяются переход в выгруженную страницу, закрытие и возврат в пару во время живого чата.
- У загруженных закреплений доступен крестик. Он отправляет страницу в сон; закрытие сохранённой вкладки разъединяет split и завершает связанный просмотр.
- Выбор друга в уведомлениях сохраняет окно отправки и черновик. Закрытие — по крестику, Escape, переходу на другую вкладку или нажатию вне окна.
- Шрифт панелей «Вместе», чата и уведомлений согласован с интерфейсом браузера. Кнопки нижней панели выровнены по центру.
- Загрузка PNG, JPEG и WebP для локального профиля и профиля Together. Изображение обрезается по центру, уменьшается до 96 px, сохраняется в PNG без метаданных; сервер передаёт в состоянии комнаты только ссылку на изображение.
- Эмодзи пространства выбирается в его меню и сохраняется в сеансе.
- Страница истории обновлений: версии, даты, разделы и списки изменений. Настройки показывают этапы проверки, загрузки, проверки SHA-256 и запуска установки, с прогрессом в МБ.
- Сайт использует цвета, типографику и капсульные элементы Night. Текст описывает возможности, требования и установку; рекламные слоганы удалены. Счётчик продолжает использовать реальные данные GitHub.

Обнови браузер и Docker-сервис Together до 0.18 для сайта и загрузки фото друзьям. После обновления сервиса перезагрузи страницу комнаты Ctrl+Shift+R. Compose-проект и volume сохраняются; команды noon без sudo — services/together/INSTALL.md.
