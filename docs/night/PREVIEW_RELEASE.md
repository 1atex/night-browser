# Night Browser 0.14.0 Preview

- В комнатах появился просмотр HTML5-видео: play/pause, перемотка, скорость и явная смена видео ведущим. Участник получает состояние и корректирует расхождение. Повторное нажатие возвращает к существующей вкладке.
- Привязка включается кнопкой «Смотреть вместе» только для выбранной вкладки. Пауза при потере связи, сохранение позиции, повторное подключение и остановка при закрытии вкладки. Статус в боковой панели; приватные окна исключены.
- Браузерные профили: название, цвет и значок с предпросмотром. Для друзей отдельно сохраняются имя и аватар из набора; ID не меняется, локальные названия не публикуются автоматически.
- Сервер protocol 2 сохраняет существующие ID и друзей. Новая Docker Compose-конфигурация по умолчанию запускает только Together на 127.0.0.1:8787; Caddy вынесен в необязательный профиль standalone. Обновление от noon без sudo и повторной настройки reverse proxy.

Для просмотра оба клиента и сервер нужно обновить до 0.14. Старые клиенты продолжают видеть друзей. Команды обновления сервера включены в ZIP в services/together/INSTALL.md. Установленная Windows-версия Night обновляется через настройки.

Проверяется настоящее HTML5 WebM-воспроизведение двумя процессами Gecko. Живой YouTube, реклама, DRM, iframe и прямые эфиры не входят в эту проверку. На сайтах с запретом автозапуска требуется один раз нажать Play; каждому нужен собственный доступ к контенту. Экран, файлы, голос и видеопоток сервером не передаются.

Совместимый Island остаётся 0.4.0. Подпись Windows пока отсутствует. Подробности — docs/night/TOGETHER.md и docs/night/VALIDATION.md.
