Night 0.2 — собственная оболочка на Firefox/Gecko. Код и runtime Zen больше не используются.

Скачать ZIP, распаковать всю папку `Night`, запустить `Night.exe`. Нужна Windows x64. Профиль создаётся в `profile`; для этой версии используй чистую папку.

- Собственная боковая панель и стартовая страница в графитовой палитре Night.
- Рабочие области, общие закреплённые сайты, поиск и перенос вкладок, восстановление сессии.
- Две страницы рядом: Alt+S. Поиск вкладки: Alt+P. Скрыть панель: Alt+B.
- Таймер выгрузки с исключениями; защита активных страниц, split view, медиа и перехвата.
- Repeater, перехват и редактирование HTTP(S) выбранной вкладки.
- Расширения и DevTools Firefox.

Перед публикацией Actions проверяет сетевые инструменты, оболочку, расширение, восстановление после перезапуска и запуск из пути с кириллицей. Там же сохраняются скриншоты и измерение памяти семи синтетических вкладок. Это не замер YouTube/ChatGPT/Censys и не доказательство ускорения рендеринга.

Gecko используется из официального Firefox 160.0; нативный движок заново не компилируется. Собственные исходники Night и точные ревизии указаны в BUILD.json. Тестовая portable-версия без автоматических обновлений; Night.exe пока не подписан.
