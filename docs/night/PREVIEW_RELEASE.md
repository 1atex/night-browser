Первая portable-preview для **Windows x64**.

1. Скачай `night-browser-0.1.0-preview-windows-x64.zip` из Assets.
2. Распакуй архив целиком.
3. Открой папку `Night` и запусти `Night.exe`.

Ничего собирать или устанавливать из инструментов разработки не нужно.
Профиль хранится в папке `profile` рядом с `Night.exe`, отдельно от Zen и Firefox.

Кнопка **Night** внизу боковой панели открывает настройки памяти и сетевые инструменты.
Захват запросов включается вручную кнопкой **Начать** для выбранной вкладки.

Сборка проверена в GitHub Actions на Windows: запуск интерфейса, перехват и
редактирование запросов, повторная отправка, отмена, исключения выгрузки вкладок
и запуск лаунчера из пути с пробелами и кириллицей.

Это тестовая версия без автоматического обновления. Нативное ядро взято из
зафиксированного релиза **Zen 1.24.2b / Gecko 160.0**; интерфейс и модули Night
упакованы из исходников проекта. Некоторые значки и системные сведения пока
сохраняют названия Zen. Экономия RAM и ускорение рендеринга ещё не измерены.

SHA-256 архива находится в `SHA256SUMS.txt`. Ревизии исходников указаны в `BUILD.json`
внутри архива. [Исходная база Zen](https://github.com/zen-browser/desktop/releases/tag/1.24.2b).
