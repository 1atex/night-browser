0.6.0 — боковая навигация, папки и прозрачное управление памятью.

- Адрес и навигация перенесены в боковую панель. Страница занимает всю высоту окна. В настройках можно вернуть верхнюю строку, выбрать плотность, показать поиск вкладок и счётчик. Ширина панели регулируется перетаскиванием края.
- Общие избранные сайты отделены от закреплений пространства. Вложенные папки сохраняют структуру и свёрнутое состояние. Вкладки и папки можно переносить мышью, включая перенос между пространствами через их переключатель.
- Импорт Zen сохраняет папки, закрепления и иконки. Для старого импорта: «Настройки → Импорт из Zen → Восстановить папки». Перед исправлением создаётся резервная копия текущей сессии; неоднозначные совпадения пропускаются.
- Закреплённые вкладки выгружаются по обычным правилам. Фоновые страницы после импорта и перезапуска не загружаются ради отображения иконок.
- Движок готовит один запасной процесс вместо трёх. В настройках памяти можно отключить резерв полностью, ценой дополнительного запуска процесса при открытии нового сайта.
- В разделе памяти показана причина удержания каждой вкладки, есть ручная выгрузка и переход к расходу отдельных процессов. Исключение для домена YouTube сохраняет вкладку даже без воспроизведения; его можно удалить отдельно.

**Ctrl+L** — адрес, **Alt+P** — поиск вкладок, **Alt+B** — боковая панель, **Alt+Shift+F** — только сайт.

Для обновления закрой браузер и замени файлы приложения, сохранив папку `profile`. Запускай **Night.exe**. Архив не содержит готового профиля.

Основа — Gecko 160.0 из официальной русской сборки Firefox. Portable-версия обновляется вручную. Исходники и сведения о движке сохранены в BUILD.json, разделе «О браузере» и about:license.
