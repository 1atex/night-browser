# Night Browser 0.15.0 Preview

- Общая пауза, продолжение, перемотка и скорость: участник управляет плеером, остальные получают его команду. Владелец по-прежнему выбирает видео и допускает людей.
- Приглашение на 24 часа: публичная страница, открытие установленного Night через night://, скачивание браузера, имя нового участника и подтверждение владельцем. Дружба для входа по ссылке не требуется.
- Чат по RTCDataChannel и голос по WebRTC. Сигналинг проходит через Together, сообщения и аудио не сохраняются сервером. Микрофон включается явно; выход закрывает соединения. Видео и комнату можно открыть рядом; активная связь не выгружается таймером памяти.
- Позднее разрешение на микрофон после выхода не оставляет захват включённым; повторное нажатие не создаёт второй запрос.
- Сайт браузера в том же Docker-сервисе: загрузка актуального установщика и реальное число скачиваний установщиков/portable ZIP из последних 100 релизов GitHub. Повторные скачивания считаются отдельно; данные кэшируются.
- Необязательный Docker TURN-релей для сетей, где P2P не устанавливается. По умолчанию остаётся прямое соединение со STUN; сам Together видеопоток и звук не ретранслирует.

Оба клиента и сервер требуют 0.15. ID/друзья сохраняются, nginx и Cloudflare для обычного обновления не меняются. Команды для noon без sudo — services/together/INSTALL.md внутри server ZIP.

Проверки используют два настоящих Gecko, локальный HTML5 WebM, реальный RTCDataChannel и RTP с искусственным микрофоном. Это не подтверждает физический микрофон, WAN/NAT/TURN или совместимость живого YouTube с рекламой/DRM/live. Каждому нужен свой доступ к контенту. Обнаружение установки браузера ограничено системой: на странице приглашения есть явная кнопка открытия и скачивание.

Совместимый Island остаётся 0.4.0. Сборка Windows пока без подписи.
