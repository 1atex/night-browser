# Night Browser 0.16.0 Preview

- «Вместе» в боковой панели: создание комнаты, приглашение по ссылке или другу, принятие заявок, просмотр, чат, выбор видео и выход без перехода в настройки.
- Быстрая кнопка микрофона и Ctrl+Alt+M. Явное включение, отмена ожидающего разрешения и остановка захвата при выходе сохраняются.
- Отдельная локальная громкость каждого участника в комнате и панели браузера. Уровни сохраняются по ID и применяются при следующем соединении.
- Полноэкранная панель только при наведении на правый верхний угол: выключение микрофона, громкость и возврат в комнату. Автоскрытие после ухода указателя; панель и сочетание отключаются в настройках.
- Готовность комнаты проверяется независимо от раннего события bridge; скрипты исключены из Rocket Loader. Исправление серверного запуска отдельно доступно в Together 0.15.1.
- Синхронизация больше не ждёт полной загрузки страницы, когда HTML5-плеер уже готов. Статусы ожидания, буферизации, готовности и восстановления связи; короткий журнал без ссылок и ключей.
- Уже открытая комната и выбранная вкладка с тем же видео переиспользуются.

Лимит — восемь человек вместе с владельцем. Для новых кнопок обнови оба клиента и Docker-сервис до 0.16. ID, друзья, Compose-проект и volume сохраняются. Команды для noon без sudo находятся в services/together/INSTALL.md внутри server ZIP; nginx и Cloudflare для обновления не меняются.

Проверки используют два Gecko, HTML5 WebM, RTCDataChannel и RTP с искусственным микрофоном. Это не нагрузочный тест восьми ПК и не проверка физического микрофона, живого YouTube с рекламой/DRM или WAN/TURN. Прямой чат между двумя реальными ПК пользователь подтвердил после повторного сигнала готовности. Совместимый Island остаётся 0.4.0. Сборка Windows пока без подписи.
