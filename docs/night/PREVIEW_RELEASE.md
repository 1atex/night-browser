0.5.2 — обновлённая верхняя панель и собственное меню.

- Единые размеры кнопок, новые значки навигации, загрузок и расширений, спокойные состояния наведения и нажатия. Значки самих расширений и их счётчики сохранены.
- Подсказки адресной строки открываются отдельной панелью с отступом, без прежней тяжёлой подсветки. Нативные поиск, история, выбор результатов и индикаторы безопасности работают как прежде.
- Кнопка «···» открывает собственное меню: окна, история, закладки, загрузки, расширения, масштаб, поиск по странице, печать, DevTools, скрытие панели и настройки. Меню работает с клавиатуры и удерживает скрывающуюся панель открытой.
- Сохранена уборка из 0.5.1: без повторяющихся названий и слоганов на стартовой, боковой панели и в настройках.

**Ctrl+L** — адрес, **Alt+Shift+F** — только сайт. Импорт Zen, профили, расширения, выгрузка вкладок и инструменты запросов сохранены.

Для обновления закрой браузер и замени файлы приложения, сохранив папку `profile`. Запуск — через **Night.exe**. Архив не содержит готового профиля.

Проверки включают реальные команды собственного меню, клавиатуру, масштаб, поиск по странице, DevTools, работу расширений, вкладки, автоскрытие, F11, обычный запуск Windows и импорт из настоящего Zen. Скриншоты меню и подсказок сняты в обычном окне Windows.

Основа — Gecko 160.0 из официальной русской сборки Firefox. Тестовая portable-версия пока не подписана и обновляется вручную. Исходники и сведения о движке сохранены в BUILD.json, разделе «О браузере» и about:license.
