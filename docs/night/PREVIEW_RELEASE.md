0.9.1 preview — актуальная основа Island и доработки интеграции.

- Island обновлён до основы [`7d9bc80`](https://github.com/1atex/night-island/commit/7d9bc801af2e41627ad7d15a6d2400bbda150aca), со стеклом, доком и новыми настройками. История обеих веток сохранена.
- Наведение или нажатие на индикатор загрузки открывает её управление. Кнопки показывают ожидание команды и не отправляют её повторно. Подсветка не сбрасывается при обновлении прогресса.
- В браузере появились понятный статус соединения, инструкция подключения и повторное подключение. Значок Island исправлен для тёмного фона.
- Часы новой вкладки обновляются на границе минуты и останавливают таймер, пока вкладка скрыта.
- Сохранены установщик, первый запуск, импорт Zen, настраиваемая навигация и сон сохранённых вкладок.

Нужен [Island 0.3.2 с интеграцией](https://github.com/1atex/night-island/releases/tag/v0.3.2-browser-preview.1). Закрой старый Island и запусти новый EXE. В Island включи **Настройки → Интеграции → Загрузки Night Browser**, а в браузере — **Настройки → Интеграции → Показывать загрузки в Island**. Приватные загрузки, адреса страниц и полные пути не передаются. Соединение по умолчанию выключено.

Выбери setup для установки или ZIP для portable. Установщик сохраняет профиль в `%LOCALAPPDATA%\NightBrowser\profile`. При обновлении portable сохрани папку `profile` рядом с `Night.exe`.

Gecko в этом выпуске не менялся; ускорение JS/CSS/HTML сайтов и снижение расхода RAM не заявляются. Сборка тестовая, без автоматического обновления и подписи Windows. Точные ревизии браузера, движка и совместимого Island записаны в BUILD.json.

Сборка из `0713d60e2febe17d724eadf99727baeb37971f78` прошла [полный Windows-прогон](https://github.com/1atex/night-browser/actions/runs/43638521985): 53 проверки логики, установку, запуск, импорт, вкладки и работу с реальным Island. Публичные setup и ZIP сверены с SHA-256, ZIP прошёл CRC-проверку; ревизии обоих приложений проверены по BUILD.json.
