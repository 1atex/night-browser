# Night Browser 0.18.1 Preview

- Сервер задаёт общую шкалу просмотра в новых комнатах. Владелец с обновлённым клиентом переводит существующую комнату при подключении плеера. Обычный отчёт ведущего не перезаписывает принятую позицию, паузу или скорость.
- Автоматический пропуск опенинга/перемотка отправляется всей комнате уже по событию начала скачка. До ответа сервера старая позиция не откатывает инициатора.
- Команды имеют ID, базовую версию управления и версию видео. Повторы не применяются заново; запоздавшая команда предыдущей серии отклоняется.
- Последующие Play/изменения скорости сохраняют ещё не принятую перемотку. Ошибка сети сохраняет команду для безопасного повтора.
- Новый плеер подключается к синхронизации при навигации, без ожидания следующего секундного опроса. Создание комнаты из текущего видео сохраняет его исходную позицию.
- Распознанная реклама по-прежнему замораживает общую шкалу; WebRTC-чат и голос работают отдельно.

Обновить нужно Night у обоих участников и Docker-сервис Together. Профиль, ID, друзья, Compose-проект и volume сохраняются. Команды без sudo: [INSTALL.md](https://github.com/1atex/night-browser/blob/v0.18.1-preview.3/services/together/INSTALL.md).

Это исправление модели синхронизации. Перехода на gRPC/WebSocket нет: транспорт пока HTTP, менять существующий reverse proxy не требуется. Разные монтажные версии эпизода и произвольная реклама без признаков плеера не считаются проверенными без ссылки на сайт.

Полный прогон Windows, Docker и Island завершился успешно: [43818237896](https://github.com/1atex/night-browser/actions/runs/43818237896). Опубликованные установщик и архивы проверены по SHA-256 и содержимому. Новые флаги Windows-теста подтверждают общий автопропуск и отсутствие отката при задержке события.
