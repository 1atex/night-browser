0.9.0 preview — меньше лишней работы интерфейса и загрузки в Night Island.

- Боковая панель собирает дерево папок за один проход и обновляет только изменившиеся строки. Неизменившиеся подписи и атрибуты больше не переписываются при каждом событии вкладки.
- В первом запуске и настройках адресная строка показывает название страницы. Ctrl+L по-прежнему открывает настоящий адрес для редактирования.
- Добавлена отключаемая интеграция загрузок с Night Island: прогресс, пауза, продолжение, отмена и показ готового файла в папке. Для неё нужен [Island с поддержкой браузера](https://github.com/1atex/night-island/releases/tag/v0.3.1-browser-preview.3).
- Сохранены установщик, мастер первого запуска, импорт Zen, управление окном справа, настраиваемая навигация и сон сохранённых вкладок.

Для связи включи **Night Browser downloads** в настройках интеграций Island и **Настройки → Интеграции → Показывать загрузки в Island** в браузере. Приватные загрузки исключены; адреса страниц и полные пути не передаются. По умолчанию соединение выключено.

В локальном синтетическом замере 100 вкладок/20 папок неизменившийся sidebar перестал создавать DOM-изменения (123 340 → 0 за 140 обновлений). Это оптимизация оболочки. Ускорение JS/CSS/HTML самих сайтов не заявляется; движок Gecko 160.0 в этой сборке не менялся. Методика и исходные замеры — `docs/night/PERFORMANCE.md`.

**Ctrl+L** — адрес, **Alt+P** — поиск вкладок, **Alt+B** — боковая панель, **Alt+Shift+F** — только сайт.

Выбери `setup.exe` для установки или ZIP для portable. Установщик обновляет приложение, профиль хранится отдельно в `%LOCALAPPDATA%\NightBrowser\profile` и сохраняется после удаления программы. Для обновления portable закрой браузер, замени файлы приложения и сохрани папку `profile` рядом с `Night.exe`. Эти варианты используют разные профили.

Тестовая сборка без автоматического обновления и подписи Windows. Сведения о движке и лицензиях сохранены в BUILD.json, разделе «О браузере» и about:license. Windows-тесты и снимки интерфейса приложены к релизу.
