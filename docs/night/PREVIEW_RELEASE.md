0.7.0 — оформление на основе Night Island.

- Единая палитра, типографика и состояния элементов: чёрные и графитовые поверхности, белая иерархия текста, компактные капсулы, Material Symbols и короткая пружинная анимация. Убраны повторяющиеся рамки, градиенты и большие карточки настроек.
- Адресная строка показывает favicon страницы. При вводе она раскрывается поверх сайта; выбор поисковика, проверка соединения, разрешения и подсказки доступны. Меню, панели загрузок и расширений получили общие стили.
- Новая вкладка стала компактнее. Палитра применяется к ней сразу. Устранена скрытая загрузка библиотек Firefox Activity Stream на новой вкладке.
- Сохраняются боковая и верхняя навигация, изменение ширины мышью, плотность, скрытие панелей, выключение анимаций и режим «Только сайт».
- Папки, пространства, импорт Zen и восстановление структуры прежнего импорта доступны в настройках. Закрепления не мешают выгрузке; для сайта можно задать отдельное исключение.
- Для новых сайтов подготовлен один запасной процесс вместо трёх. Его можно отключить в настройках памяти. Это не означает, что процессы расширений или GPU перестанут расходовать память.

**Ctrl+L** — адрес, **Alt+P** — поиск вкладок, **Alt+B** — боковая панель, **Alt+Shift+F** — только сайт.

Для обновления закрой браузер и замени файлы приложения, сохранив папку `profile`. Запускай **Night.exe**. Архив не содержит готового профиля. Палитра выбирается в «Настройки → Внешний вид».

Основа — Gecko 160.0 из официальной русской сборки Firefox. Portable-версия обновляется вручную. Сведения о движке сохранены в BUILD.json, разделе «О браузере» и about:license. Лицензия Material Symbols включена в архив. Конкретное снижение расхода памяти для Gmail или YouTube не заявляется.
