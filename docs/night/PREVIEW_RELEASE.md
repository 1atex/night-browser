# Night Browser 0.13.0 Preview

- Обновление установленной Windows-версии из настроек: проверка релиза, загрузка установщика, SHA-256, подтверждение закрытия всех профилей и повторный запуск. Заходить на GitHub вручную не требуется; файлы пока размещены в официальных GitHub Releases. Portable обновляется вручную.
- После встроенного обновления открывается локальная страница изменений. Следующие версии показывают её один раз в каждом профиле.
- Основа Night Together: личный ID, запросы дружбы с подтверждением, список друзей, приглашения, комнаты по явно выбранной ссылке. Сервер проверяет участников, роли и ревизии команд.
- Сервер на Node.js без внешних зависимостей, атомарное хранение состояния и инструкция запуска через HTTPS. В клиенте закреплён browser.night-watchers.com. Отдельный серверный архив и команды установки включены в релиз; сервис нужно развернуть на сервере владельца.

Этот выпуск готовит совместный просмотр: синхронизация реальных плееров сайтов, компенсация задержки, передача экрана и файлов ещё не подключены. Открыть ссылку из комнаты можно; каждому нужен собственный доступ к сайту. Radmin VPN и отдельный клиент не нужны.

Совместимый Island остаётся 0.4.0. Установщик сохраняет профили. Сборки пока без подписи Windows; SHA-256 защищает от повреждения загрузки, но не заменяет независимую подпись издателя.
