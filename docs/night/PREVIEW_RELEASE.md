# Night Browser 0.9.2 Preview

- Исправлено подключение к Island после повторного скачивания: `night-island (1).exe`, `night-island (2).exe` и другие нумерованные копии теперь распознаются автоматически.
- После закрытия последней открытой страницы появляется стартовая. Спящие вкладки из папок не открываются сами; Ctrl+W выгружает сохранённую страницу и сохраняет её в папке.
- После открытия новой вкладки можно сразу печатать. Поиск на стартовой использует выбранную систему и принимает адреса.
- Индикатор в боковой панели показывает файл и прогресс; нажатие раскрывает настоящий Island. Доступно общее оформление: фон, акцент и анимации. Индикатор и синхронизация отключаются отдельно.
- В настройках интеграции видна причина сбоя: Island не запущен, Windows запретила доступ, соединение занято, имя приложения не распознано или версия протокола несовместима. При наличии отображается код ошибки Windows.
- После успешного подключения сообщение об ошибке очищается. Автоматическое переподключение и кнопка ручного повтора сохранены.

Для новых визуальных возможностей нужен [Island 0.3.3](https://github.com/1atex/night-island/releases/tag/v0.3.3-browser-preview.1). С Island 0.3.2 продолжают работать передача и управление загрузками. Включи **Загрузки Night Browser** в настройках Island и **Показывать загрузки в Island** в браузере. Приватные загрузки, адреса страниц и полные пути не передаются.

Установщик обновляет файлы браузера, сохраняя профиль. Перед установкой закрой Night Browser. ZIP доступен для переносной установки.
