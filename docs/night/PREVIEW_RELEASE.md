Night 0.3 — новый интерфейс и собственная идентичность приложения в Windows.

Распакуй ZIP целиком в новую папку и запусти **Night.exe**. Рядом появится ярлык **Night.lnk**. Старое закрепление от 0.2 нужно удалить и закрепить новое окно Night: старый ярлык Windows продолжает указывать на старый файл.

- Собственные настройки Night: внешний вид, вкладки, память, приватность, поиск и сведения о браузере.
- Три палитры, плотность и ширина боковой панели; изменения применяются сразу.
- Переработаны боковая панель, иконки, стартовая страница и состояния элементов. Интерфейс браузера на русском.
- Сетевые инструменты расположены в нижней рабочей панели: захват, редактирование и ответ видны рядом. Настройки памяти больше не занимают правую часть страницы.
- Windows-приложение называется **Night Browser**, имеет значок и ресурсы Night. Для окна заданы собственные AppUserModelID, название и команда повторного запуска через Night.exe.
- Отключены предложения Firefox о закреплении, аккаунте, рекомендациях и других продуктах.

Actions проверяет обычный первый запуск без Marionette/headless, видимый интерфейс через Windows UI Automation, имя и ресурсы EXE, свойства окна для панели задач и запуск через ярлык из пути с кириллицей. Скриншоты обычного запуска и настроек приложены к релизу. Сетевые инструменты, расширения, вкладки, настройки, восстановление сессии и выгрузка памяти также проверяются в настоящем браузере.

Основа — Gecko 160.0 из официальной русской сборки Firefox. PE-ресурсы Windows заменены на Night; изменённый EXE не сохраняет подпись Mozilla. Launcher и приложение пока не подписаны. Версия тестовая, автоматические обновления отключены. Сведения о движке и лицензии сохранены в разделе «О Night» и BUILD.json.
