# Обновление Night

Установленная Windows-версия: «Настройки → Обновления → Проверить обновления». Night проверяет GitHub Releases API в официальном репозитории и выбирает более новую совместимую preview-версию. Пользователю не нужно заходить на GitHub или вручную скачивать файл. Сами файлы пока размещены на GitHub; при недоступности хостинга проверка покажет ошибку.

После нажатия «Установить и перезапустить» требуется подтверждение закрытия окон всех профилей. Установщик скачивается через механизм загрузок Gecko, проверяется по SHA-256 из того же релиза. Временный helper повторно проверяет сумму, запрашивает обычное закрытие процессов этой установки, ожидает завершения до двух минут и запускает установщик. Принудительного убийства процессов нет; оставшиеся открытыми окна отменяют обновление. После успешной установки запускается выбранный профиль. Данные находятся вне каталога приложения.

Следующий запуск новой версии открывает локальную страницу изменений один раз в каждом профиле. Номер версии показывается из общего модуля версии. Автоматического скачивания/установки без команды пользователя нет. Portable пока обновляется заменой файлов вручную: встроенная установка заблокирована, чтобы не менять местоположение данных portable.

SHA-256 обнаруживает повреждённую загрузку; метаданные и файлы доверяются HTTPS официального GitHub-репозитория. Это не отдельная криптографическая подпись издателя. Сборки пока без подписи Windows. Для независимости от хостинга и более сильной проверки нужны подписанный update manifest, встроенный публичный ключ и подпись установщика.
