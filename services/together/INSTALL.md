# Night Together 0.16.0: Docker и существующий reverse proxy

Команды рассчитаны на пользователя noon, rootless Docker и каталог `/home/noon/night-together`. Входящий домен уже обслуживает nginx/Caddy на хосте; приложение слушает только `127.0.0.1:8787`. Для обновления работающего сервиса права администратора не нужны.

## Обновление сервера без смены ID

```sh
cd /home/noon
curl -fL https://github.com/1atex/night-browser/releases/download/v0.16.0-preview.3/night-together-server-0.16.0.zip -o night-together-server-0.16.0.zip
unzip -o night-together-server-0.16.0.zip -d /home/noon/night-together
cd /home/noon/night-together/services/together
docker compose -f compose.yaml -f compose.proxy.yaml up -d --build together
curl -f http://127.0.0.1:8787/health
curl -f https://browser.night-watchers.com/health
```

Для быстрых кнопок звука и полноэкранной панели обнови оба Night до 0.16 через Настройки → Обновления и этот Docker-сервис до 0.16. После обновления контейнера перезагрузи страницу комнаты Ctrl+Shift+R. Сервер сохраняет совместимость со старым клиентом 0.15; новая панель требует 0.16.

Оба запроса должны вернуть `{"ok":true}`. Если на ПК ещё версия ниже 0.15, обнови Night через Настройки → Обновления. Само обновление сервера не меняет ID и список друзей: имя Compose-проекта и volume `night-together_together_data` сохранены. Клиент 0.13 продолжает видеть друзей, но для синхронизации видео обоим нужен 0.15.

Если сервер уже работает, его nginx, SSL и Cloudflare для этого обновления не перенастраиваются. Новая базовая compose-конфигурация публикует только loopback-порт; дополнительный Caddy находится в профиле `standalone` и по умолчанию не запускается. Старый compose.proxy.yaml остаётся совместимым; используй одинаковые `-f` аргументы при следующих операциях.

## Как смотреть

1. Нажми «Вместе» внизу боковой панели. При уже настроенном ID повторная регистрация не нужна; иначе нажми «Подключить Together».
2. Один участник создаёт комнату по ссылке на видео, затем нажимает «Пригласить» у друга.
3. Друг принимает приглашение кнопкой «Войти».
4. Оба нажимают «Смотреть» в панели «Вместе». Откроется отдельная вкладка, связанная только с этой комнатой. Повторное нажатие возвращает к ней.
5. Любой участник управляет Play/Pause, перемоткой и скоростью в самом плеере. Остальные браузеры следуют за командой. Если сайт блокирует автозапуск, участник один раз нажимает Play на видео.

Ведущий может явно сменить ссылку в комнате; связанные вкладки перейдут на неё. При потере связи плееры приостанавливаются; повторное соединение сохраняет ID. Закрытие связанной вкладки или «Остановить синхронизацию» снимает привязку. Перехватываются только события HTML5 video в выбранной вкладке; история остальных вкладок не передаётся.

Протокол проверен на двух настоящих процессах Gecko с локальным HTML5 WebM-видео. Сетевое воспроизведение YouTube, реклама с разной длительностью, DRM, прямые эфиры и видео внутри iframe не включены в эту гарантию. Каждому участнику нужен собственный доступ к сайту; видеопоток идёт с сайта, а не через Together. Передачи экрана и файлов нет. Чат и голос подключаются отдельно по WebRTC.

## Приглашение, чат и голос

В комнате нажми «Скопировать приглашение». Отправь ссылку любым удобным способом. Получатель открывает её, при необходимости скачивает Night, затем нажимает «Открыть в Night» и «Попроситься в комнату». Установка не может незаметно перенести ссылку из другого браузера: после установки открой приглашение повторно. Владелец видит имя и принимает/отклоняет заявку в настройках или комнате. Ссылка действует 24 часа; её обладатель не получает доступ без подтверждения. Установщик регистрирует night:// без прав администратора.

«Чат и голос» открывает комнату. «Подключить чат» устанавливает WebRTC-соединения с участниками; микрофон включается отдельно и запрашивает разрешение браузера. Кнопка «Видео рядом с чатом» открывает split view. Индикатор в боковой панели возвращает к комнате. Активная вкладка связи защищена от автоматической выгрузки; закрытие вкладки выключает микрофон и соединения. История чата остаётся только в памяти текущей страницы, до 200 сообщений.

Сайт находится на https://browser.night-watchers.com/ и начинает работать после обновления этого же контейнера. /api/releases получает реальные download_count GitHub для установщика и portable ZIP, без серверного архива и скриншотов; кэш — 10 минут. Это количество скачиваний последних 100 релизов, а не уникальных людей. При недоступности GitHub сайт не выдумывает число.

Кнопка микрофона рядом с «Вместе» и Ctrl+Alt+M переключают свой микрофон. В панели есть громкость каждого участника; она сохраняется локально и не меняет звук у остальных. «Открыть чат» автоматически подключает связь, микрофон остаётся выключенным до явного включения.

В полноэкранном видео наведи указатель на правый верхний угол: появится компактная панель выключения микрофона и громкости. Она скрывается через 2,5 секунды после ухода указателя. Включение микрофона — из интерфейса браузера или сочетанием клавиш. Панель и сочетание можно отключить в настройках Together. Прозрачность и размытие оверлея переключаются отдельно. Максимум — восемь человек вместе с владельцем; это лимит комнаты, а не гарантия качества на восьми ПК.

## Если прямое соединение не устанавливается

Для части NAT/корпоративных сетей нужен TURN-релей. Он не обязателен для обычного обновления и не запускается автоматически. Подготовлен compose.turn.yaml: Coturn на 3478 UDP/TCP и диапазоне 49160–49200 UDP, с временными HMAC-паролями. Доступность этих портов с интернета проверяет администратор firewall. HTTPS сайта остаётся через существующий proxy; TURN не пропускается через HTTP/Cloudflare proxy. Эта конфигурация не предоставляет TURN/TLS на 443 и может не помочь в сети, разрешающей только такой порт.

В каталоге services/together создай закрытый .env:

```sh
umask 077
python3 - <<'PYCONFIG'
from pathlib import Path
import secrets
p = Path('.env')
if p.exists():
    raise SystemExit('.env уже существует: сохрани его и добавь TURN-параметры вручную')
p.write_text('NIGHT_TURN_SECRET=' + secrets.token_hex(32) + '\nNIGHT_TURN_PUBLIC_IP=144.91.104.48\nNIGHT_TURN_URL=turn:144.91.104.48:3478?transport=udp,turn:144.91.104.48:3478?transport=tcp\n')
p.chmod(0o600)
PYCONFIG
docker compose -f compose.yaml -f compose.proxy.yaml -f compose.turn.yaml up -d --build together turn
```

При следующих обновлениях используй те же три -f аргумента. Секрет не включён в ZIP и не публикуется страницей: клиентам выдаются только временные credentials на час. Для долгой сессии переподключи чат после истечения credentials. WebRTC шифрует чат/аудио и при релейной передаче. TURN потребляет трафик сервера; при прямой связи его нет. Публичные WAN/TURN-пути не входят в локальную проверку с двумя Gecko.

## Профили

«Как тебя видят друзья» в разделе Together: имя до 40 символов, цвет и значок из набора. Эти данные видят друзья и участники комнаты; ID сохраняется. Сервер 0.15 хранит настройки в существующем файле состояния.

Локальные профили браузера настраиваются отдельно: Настройки → Профили и Sync → Настроить. Можно изменить название, цвет и значок кнопки профиля. Эти локальные названия не отправляются друзьям автоматически.

## Диагностика

```sh
cd /home/noon/night-together/services/together
docker compose -f compose.yaml -f compose.proxy.yaml ps
docker compose -f compose.yaml -f compose.proxy.yaml logs --tail=80 together
```

Если localhost отвечает, а домен нет — проблема в существующем reverse proxy/DNS. Для proxy на хосте upstream `http://127.0.0.1:8787`. Готовый HTTP vhost — deploy/nginx.http.conf; подключает и перечитывает его администратор. Если proxy в контейнере, его localhost отличается от localhost хоста: настрой общую сеть или доступ к loopback хоста через конфигурацию proxy.

## Резервная копия

```sh
cd /home/noon/night-together/services/together
docker compose -f compose.yaml -f compose.proxy.yaml stop together
docker run --rm -v night-together_together_data:/data:ro -v "$PWD":/backup alpine:3.22 tar czf /backup/night-together-backup.tgz -C /data .
docker compose -f compose.yaml -f compose.proxy.yaml start together
chmod 600 night-together-backup.tgz
```

Копия содержит ключи ID: храни её закрыто. `docker compose down` сохраняет volumes, а `down -v` удаляет данные. Для восстановления останови сервис и распакуй копию в тот же volume с сохранением владельца файлов.

Для первого запуска нужны Docker Engine и Compose v2. Код сервера не требует npm-зависимостей. Это закрытый пилот; для массового публичного сервиса нужны дополнительная защита регистрации, мониторинг и процедура удаления/восстановления ID. Технические детали — docs/night/TOGETHER.md.
